Why are Level and Maze disabled?

The original speed levels and mazes are not yet verified, so no options or counts are shown. Continue is enabled only after the Pause preview. The direction buttons only show the last input; nothing moves.

Classic Games is an independent project inspired by Nokia 3310 Snake II. Unofficial; not affiliated with or endorsed by Nokia.

Instructions

This is an interface prototype. The game itself is not implemented yet, so there is nothing to play.

Planned controls: arrow keys and the on-screen direction buttons. Other key mappings and pause shortcuts await owner approval.

Original rules (speed, mazes, scoring, bonus food) are still being verified and are not described here.
